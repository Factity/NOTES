Prompt generation: a new interpretability method for language models (which reliably finds prompts that result in a target completion). This is good for:

eliciting knowledge
generating adversarial inputs
automating prompt search (e.g. for fine-tuning)


Because text inputs are discrete tokens, they instead optimize in the continuous embedding space, with regularization to keep embeddings near real tokens. By maximizing the log‑probability of a target token, they can generate adversarial or informative prompts.

 This method can be used to elicit latent knowledge, find adversarial inputs, or automate prompt search.
